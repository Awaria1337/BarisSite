## 1. Content-hashed filenames (HIGH — cache bug)
Problem: `public/_headers` serves `/img/*` as `Cache-Control: immutable, max-age=1y`, but output
names are `<id>-<w>.<ext>` with no content hash. When the client drops a real photo with the same
basename into `assets/photos/` (overriding stock), visitors keep the old cached image. Also the
mtime-based skip misses files copied with old mtimes (Finder preserves dates).
Fix:
- Compute `hash = sha256(sourceFileBytes)` → first 10 hex chars. Output names become
  `public/img/<id>.<hash>-<w>.avif|webp`.
- Skip work if all expected outputs for that `<id>.<hash>` already exist (no mtime logic).
- Stale cleanup: delete every file in `public/img/` that is not an expected output of the current
  run (covers old hashes and removed ids). Never delete outside `public/img/`.
- Manifest entries gain `"file": "<id>.<hash>"` (the stem). Keep all existing fields.
- `picture.tsx`: build every URL from `images[id].file` instead of `id`
  (`/img/${file}-${w}.${ext}`), including `imageSrc`, `imageSrcSet`, and the `preload()` call.
  Exported API unchanged.
- Re-run the script; confirm `public/img` contains only hashed names and the count is 2 × Σwidths.

## 2. Lightbox fixes (`lightbox-gallery.tsx`)
- Clicking the backdrop (the `<dialog>` element itself, i.e. `event.target === dialogRef.current`)
  closes it. Clicks on the image/buttons must not close.
- Allow pinch-zoom on the image: replace any `touch-action: pan-y` / `touch-pan-y` with
  `touch-action: pan-y pinch-zoom` (Tailwind: `touch-pan-y touch-pinch-zoom`). Keep swipe navigation
  for single-pointer horizontal swipes only (ignore when 2+ pointers are down).
- iOS background scroll: while open, set `document.documentElement.style.overflow = "hidden"` and
  restore the previous value on close/unmount.
- Any element carrying `aria-label` without an interactive role: either give it a proper role
  (`role="group"` with `aria-roledescription` is NOT wanted) — simplest: move the label to the
  `<dialog>` via `aria-label="Fotoğraf görüntüleyici"` and remove the stray one.
- Keep: Esc, ←/→, focus return, ViewTransition, `priority={index < 2}` on the first tiles and the
  `sizes` logic already present.
